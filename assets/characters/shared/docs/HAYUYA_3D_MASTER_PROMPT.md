# HAYUYA 3D MASTER PROMPT

Use whenever a character needs preparation for **Hayuya 3D** (team alias for **Hunyuan3D**).

## Phase 1 — Preview
Create a turnaround preview containing:
1. Front
2. Front 45 Right
3. Right Side
4. Back 45 Right
5. Back
6. Back 45 Left
7. Left Side
8. Front 45 Left

Rules:
- same identity
- same face
- same hair
- same clothing
- same accessories
- same proportions
- full body
- neutral background
- centered
- consistent scale
- no duplicated orientation

Stop for approval.

## Phase 2 — Individuals
After approval, create all eight views individually, high quality, portrait/full-body, matching the approved preview.

## Mandatory verification
Before finishing:
- right vs left side are distinct
- both front 45s are distinct
- both back 45s are distinct
- all eight views exist
- mirror shortcuts did not corrupt asymmetric details

Interpret **"prepare it for Hayuya 3D"** as this complete workflow.
