# Expanded Sanctum CC0 model/animation library

This folder contains selected CC0 third-party assets used as legal production starting points and animation sources.

Important:
- Base meshes are not final Sanctum art.
- Keep source provenance.
- Do not ship a downloaded model unchanged as a named Sanctum hero character.
- Universal Animation Library 2 is used for retargetable locomotion/combat/zombie motion.
- Nightmare Monsters and Glance are especially useful as horror silhouettes/material/rig references.
