- Felix

These aliases authorize use of the Felix / Volnox collaboration workflow only. They do not grant GitHub permissions by themselves.

## Repository owner

The authenticated repository owner remains the sole final promotion/merge authority for work entering the main project.

## Security note

A name typed into ChatGPT is not identity verification. GitHub account permissions, branch protection/rulesets, and required review are the real enforcement mechanisms.
