## Research policy

When implementing an original Xziel quest inspired by one of these patterns:

1. Verify the current source.
2. Extract the **mechanic class**, not the proprietary expression.
3. Rename/retheme/rebuild it around our own world.
4. Do not copy dialogue, symbols, textures, characters, map geometry, sound, animation or story.
5. Record what changed in the Xziel design so the inspiration remains traceable but the execution is original.
