# Sanctum free model library

These are real third-party models downloaded from OpenGameArt and converted/copy-selected into OBJ for DCC-independent work.

Rules:
- Prefer CC0 assets for production bases.
- CC-BY assets require attribution in shipped credits.
- Do not treat a base model as final art; rework clothing/materials/silhouette to match Sanctum references.
- Keep SOURCE.json beside every model.
- Do not import assets with personal-use-only or unclear licenses.

Current intended uses:
- Male City Zombie / Mobile Ready Zombie / Thin Zombie: undead body and animation references.
- Monk: clergy/robe base.
- Old Lady / Female Character / Female Body: La Llorona, nun, and female apparition bases.
- Giant Mutant / Monster: Censer Brute and Reliquary Horror proportion/creature bases.
- Lowpoly Kid: Lost Child / Waterbound Child base.
- Male 3D: clean male anatomy/base for Grave Sexton, Bell Ringer, Penitent Deacon.
