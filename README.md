# Xziel-

Native Android port work for Nazi Zombies: Portable (NZ:P).

This repository is being used for the real native/offline Android build: SDL2 + Vril Engine + Android NDK, with the official open NZ:P assets/game code bundled for local play rather than a WebView/cloud wrapper.

## Current target

- Android arm64-v8a first
- Native SDL2 runtime
- Vril Engine base
- Mobile touch controls and gyroscope
- Offline bundled game data
- GitHub Actions APK builds

Upstream projects and their licenses/attribution will be preserved as the port is integrated.
