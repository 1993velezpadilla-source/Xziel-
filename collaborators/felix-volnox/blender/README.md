# Blender

Owner Blender sources/scripts outside this workspace are reference/reusable inputs only. If they need changes, copy or wrap them here and preserve the original source path/commit.

Store .blend sources, scripts, manifests, renders and exports in this workspace or the relevant Felix asset package.
