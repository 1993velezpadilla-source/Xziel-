# Nacht Enchanted audio strategy

The practice map has two audio lanes:

1. **Reference/private lane** — the existing optional local-import hooks can
   play user-supplied classic WaW cues for private comparison. Those bytes are
   never downloaded or packaged by CI.
2. **Original/public lane** — replace each functional cue with CC0 or otherwise
   redistribution-safe material. `assets/nacht_enhanced/free_audio_sources.json`
   records the current CC0 shortlist.

The target roles are more important than copying a specific recording:
exterior wind, stressed wood/metal, electrical faults, low horror bed,
supernatural round cue, Mystery Box event cue, round-end accent and game-over
sting. The eventual original Xziel map should retain the tension curve while
using its own recordings/music identity.
