## Archived/older release discovery

The release category has older pages beyond the currently surfaced list (for example Corner and other migrated forum maps). Those are not allowed to disappear from research simply because the category UI paginates them. When source packages are inspected, add them as immutable source snapshots rather than replacing this inventory.

## Extraction status definitions

- `SOURCE_EXTRACTED`: editable source parsed into entity/target graph.
- `SOURCE_AVAILABLE`: editable source is explicitly published but not yet mirrored/indexed here.
- `MECHANICS_VERIFIED`: release/changelog/comments establish the mechanic.
- `BROKEN`: release evidence explicitly says the mechanic does not currently complete.
- `SURVIVAL_ONLY_OR_NO_QUEST_FOUND`: useful normal map progression, but no substantial quest chain established.
- `UNVERIFIED`: do not guess.
