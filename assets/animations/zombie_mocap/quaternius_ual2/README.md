# Quaternius Universal Animation Library 2 (CC0)

This is a secondary, fully redistributable human-authored animation source.

- Official pack: https://quaternius.com/packs/universalanimationlibrary2.html
- License: CC0 1.0 Universal / Public Domain Dedication.
- The pack contains 130+ humanoid animations and explicitly includes zombie locomotion.
- The standard GLB stores the animation clips together on one universal humanoid rig.

This source is kept separate from the **CMU optical motion-capture** clips because Quaternius is a human-authored animation library rather than a claim that every clip was captured from a performer in an optical mocap volume.

The importer writes:
- `UAL2_Standard.glb`
- `License.txt`
- `animation_names.txt` — every embedded animation name
- `zombie_animation_names.txt` — names containing zombie/infected/undead terms, when present

Source mirror used by automation: https://github.com/agentkaerf/FreeModels
Original author: Quaternius
