# CHARACTER IMAGE PREP — HAYUYA 3D

**Hayuya 3D** is the team's short name for the **Hunyuan3D character-image preparation workflow**.

When a teammate asks for:
- "a photo for the 3D model"
- "prepare this for Hayuya"
- "make refs for Hayuya 3D"
- "turn this character into a 3D-ready reference"

follow:
- `assets/characters/shared/docs/HAYUYA_3D_MASTER_PROMPT.md`
- the character-specific `hayuya3d/docs/HAYUYA_3D_IMAGE_PREP_RULES.md`

Default workflow:
**preview first → approval → 8 unique individual views → validation → 3D handoff**

Never skip the anti-duplicate orientation check.
