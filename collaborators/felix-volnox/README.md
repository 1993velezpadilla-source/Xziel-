# Felix / Volnox Collaboration Sandbox

Dedicated workspace for Felix / Volnox inside the ZOMBIESSSSSSS PORTABLE repository.

## Goal

Felix / Volnox can study the full project, use the discoveries and pipelines already developed, and build maps/assets/models independently without changing the owner's active project work.

## Branch

Work on:

`collab/felix-volnox-sandbox`

Primary writable area:

`collaborators/felix-volnox/`

## What this workspace can use

For reference, Felix / Volnox may inspect the rest of the repository: Call of Duty Zombies research, horror/map design notes, tooling, model-generation workflows, existing maps, audio/sound-effect libraries or references, asset catalogs, engine documentation, and optimization knowledge.

Those areas are reference/read-only for Felix / Volnox unless the owner explicitly approves a promotion or targeted edit.

## What Felix / Volnox can create here

- `maps/` — maps and map-specific work
- `models/` — models and model-generation output
- `assets/` — collaborator-created/imported assets with provenance
- `audio/` — collaborator-created/approved audio work and references
- `audits/` — repository audits and findings
- `proposals/` — proposed changes before promotion
- `experiments/` — isolated prototypes
- `research/` — source-backed research
- `handoff/` — material prepared for owner review

## Promotion rule

Nothing in this workspace becomes part of the main project automatically. Promotion requires owner review and approval through a Pull Request/diff.

See `CHATGPT_ENTRY.md` before AI-assisted work and `WORK_RULES.md` for isolation rules.
